# 调查能力迭代审计

基线为公开仓库 main 的 `44f7a17`。审查范围包括两份 README、Skill 指引和参考、查询与传输模块、验证脚本、测试和 CI。原版 75 项测试在本机通过。

| 核查项 | 基线发现 | 本轮处理 |
| --- | --- | --- |
| 功能与文档 | 区块范围内的顶层交易和回执已实现。没有时间窗口、日志或 ABI 解码 | 原入口保留，调查模式独立使用 2.0 输出 |
| RPC、限速和超时 | 读方法允许列表、共享速率、截止、TLS 及 HTTP 连接复用均有实现和测试。5 rps 约束调度，不能当节点服务承诺 | 保留传输层。新路径共享 RPC 预算，收尾预留快照复查时间。索引有独立的分页上限并共享总截止 |
| 数据完整性 | 结束区块读取失败后，如果复查返回有效块，基线仍可能将链一致性字段标为真。部分区块内部重复涉及非目标记录时未被识别 | 要求扫描期及复查期结束块匹配，拦截同块内涉及非目标行的重复哈希。旧模式保留相关交易重复报告 |
| 指标 | 原生币金额只累计成功顶层 value。集中度基于直接 to 交易。原始交易只有指纹 | 调查模式保留原始交易和日志、分开分析工作量和代币事件，扩展 UTC 趋势和对手地址分布 |
| 结构与测试 | RPC 传输与纯统计已经拆开，扫描编排同时负责范围、证据和输出。既有测试重点在区块、回执和网络生命周期 | 复用扫描器和金额统计。新模块分别测试索引、日志身份、ABI、报告、时间搜索和真实回环入口 |

实施顺序为审计与基线测试、修复覆盖判定、接入数据适配器、实现事件与指标、集成报告、验证与文档。长窗口优先采用索引候选发现，RPC 提供独立于索引字段的证据核验。同一 RPC 的响应仍存在遗漏、节点滞后或重组风险。没有索引覆盖水位时，候选检索结束也不会标为完整。

下一轮应先选定并验证支持 Monad Testnet、提供索引水位或明确覆盖证明的服务，分别用已知交易和空范围验收 7 天、30 天、分页边界、限流和截断行为。随后处理历史代理 ABI 与实现版本对应，并用真实 ERC-20 Transfer、Approval 和状态失败交易补足验收。
